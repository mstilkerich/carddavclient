CardDavClient.php : 38

Implements the operations of the CardDAV protocol.

This class implements the lower level interactions with the CardDAV server that are utilized by the higher-level operations offered by the public entities (AddressbookCollection etc.) and services (Sync, Discovery.

An application interacting with the carddavclient library should not interact with this class directly, and it is considered an internal part of the library whose interfaces may change without being considered a change of the library's API.

CardDavClient.php : 211

Requests the server to create the given resource.

public createResource(string $body, string $suggestedUri[, bool $post = false ]) : array<string, string>

On success, the actual URI of the new resource is contained in the returned array.

Parameters
$body : string

The content of the newly created resource.

$suggestedUri : string
  • If $post=false: The suggested new URI for the resource to create. If a resource by that name already exists, names will be derived from this URI by appending a numerical suffix for a limited number of retries.
  • If $post=true: The "Add-Member" URI to perform the POST request to. The server chooses the URI of the new resource.
$post : bool = false

If true, use a POST instead of a PUT request to create the resource (RFC 5995).

isDirectMember()

CardDavClient.php : 626

Checks whether a URI identifies a direct member of a collection.

public static isDirectMember(string $collectionUri, string $memberUri) : bool

A direct (internal) member of a collection has the same origin as the collection, and its path consists of the path of the collection plus one additional path segment (RFC 4918, section 5.2). Path segments are compared after percent-decoding them, and empty path segments (e.g. from trailing slashes) are ignored.

Parameters
$collectionUri : string

The absolute URI of the collection

$memberUri : string

The absolute URI to check

Return values
bool —

True if $memberUri identifies a direct member of the collection identified by $collectionUri

public updateResource(string $body, string $uri[, string $etag = "" ]) : string|null

Normally, the ETag of the existing expected server-side resource should be given to make the update conditional on that no other changes have been done to the server-side resource, otherwise lost updates might occur. However, if no ETag is given, the server-side resource is overwritten unconditionally.
