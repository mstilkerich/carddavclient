HttpClientAdapter.php : 40

Abstract base class for the internal HTTP client adapter.

This class intends to decouple the rest of this library from the underlying HTTP client library to allow for future replacement.

We aim at staying close to the PSR-18 definition of the Http ClientInterface, however, because Guzzle does currently not expose this interface (in particular its Psr7Request creation), compliance would mean to define an own implementation of the Psr7 Request Interface to create request objects, that would have to be deconstructed when interaction with Guzzle again.

So for now, this is not compliant with PSR-18 for simplicity, but we aim at staying close to the definition considering a potential later refactoring.

The comparison is case-insensitive and considers the default port of the scheme if the port is not given. IP addresses are compared by their binary value, so different notations of the same IPv6 address and the IPv4-mapped IPv6 notation of an IPv4 address are considered the same host.

mayAuthenticate()

HttpClientAdapter.php : 108

Checks whether the credentials may be sent with a request to the given URI.

public mayAuthenticate(string $uri) : bool

The credentials are bound to the origin (scheme, host and port) of the base URI of this HTTP client. For a request to a different origin, the auth_origin_callback of the HTTP options decides if configured, otherwise the credentials are not sent. Independent of the callback, credentials are never sent over plain HTTP if the base URI uses HTTPS.

Request-specific options, merged with/override the default options of the client. Supported options are:

getOrigin()

HttpClientAdapter.php : 158

Provides a normalized string representation of the origin of an absolute URI.

private static getOrigin(string $uri) : string|null

The result is a URL of the form scheme://host:port, with scheme and host in lowercase. If the URI does not contain a port, the default port of the scheme is used for http and https; for other schemes, the port is omitted. IP addresses are converted to their canonical notation, with IPv4-mapped IPv6 addresses converted to the IPv4 address.

$uri : string
Return values
